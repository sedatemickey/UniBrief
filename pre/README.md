# 第一次课堂展示材料索引

本目录服务于“需求分析、系统架构与数据库设计”第一次课堂展示，不代表系统已经实现。文档中统一使用“设计为、计划实现、预期”等措辞，避免把当前 Phase 0 尚未开始的项目讲成已完成功能。

## 推荐使用顺序

1. 先读 `00_项目审阅与汇报策略.md`，确认项目定位、讲解主线和待定设计问题。
2. 用 `04_需求分析.md` 形成报告中的需求分析章节。
3. 按 `05` 至 `09` 的绘制说明手工完成各种图。
4. 按 `03_PPT大纲.md` 制作 PPT。
5. 用 `01_演讲大纲.md` 控制节奏，用 `02_演讲稿初稿.md` 练习逐页讲解。
6. 展示前使用 `10_答辩准备与讲解建议.md` 做自检和问答演练。

| 文件 | 用途 |

| `04_需求分析.md` | 系统定义、边界、角色、功能、数据、事务及非功能需求 |
| `05_用例图绘制说明.md` | 用例图中的参与者、用例、关系和布局 |
| `06_业务流程图绘制说明.md` | 主业务流程、导入去重、信息聚合、AI 失败重试流程 |
| `07_数据库ER图绘制说明.md` | 概念 ER 图的实体、联系、基数、属性和拆图方案 |
